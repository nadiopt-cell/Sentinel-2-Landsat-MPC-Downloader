description=Search Sentinel-2 L2A and Landsat C2 L2 (missions 4-9) scenes on Microsoft Planetary Computer (STAC), download only the needed bands and build standard RGB syntheses, NDVI/NDMI and individual band rasters as GeoTIFF layers.
about=Searches Sentinel-2 L2A and Landsat Collection 2 Level-2 scenes through the Microsoft Planetary Computer STAC API (no VPN needed). Sentinel-2 and Landsat are on separate tabs; Landsat missions 4-9 are selected inside the Landsat tab (Landsat 1-3 / MSS are not hosted by Planetary Computer). Downloads only the bands required by the selected products, resamples Sentinel-2 20/60 m bands to 10 m and builds 8 RGB composites plus NDVI/NDMI for Sentinel-2 and 4 standard composites, NDVI and per-band downloads for Landsat, added to the project as GeoTIFFs. Personal-use plugin, not published to the QGIS repository.

changelog=0.4.9 - empty search diagnostics: when a search returns no scenes (Landsat revisits one place only every 16 days, so short date windows are often empty), the plugin re-checks the catalog with the window widened by +/-16 days and without cloud/mission filters, and explains what to do: it lists example scene dates nearby, or reports a network/access problem when even the filter-free probe finds nothing; the Landsat tab note mentions the 16-day revisit. ; 0.4.8 - the main window now fits small screens: the search form (area of interest, dates, data tabs, output options) lives in a scrollable area, while the progress bar, status line and buttons stay pinned at the bottom and always remain visible; the dialog opens at the form's natural size capped to the available screen, so on short screens a scrollbar appears instead of a window that does not fit. ; 0.4.7 - bugfix: downloading several large scenes no longer freezes the plugin window - the downloader used to report progress on every downloaded megabyte, flooding the Qt event queue with cross-thread signals (the window stopped responding and kept changing its shape); progress is now reported at most about 3 times per second plus one update per finished file, the status line keeps a fixed two-line height so the dialog no longer resizes while downloading, and adding many result layers to the project shows a status message instead of a silent pause. ; 0.4.6 - multi-scene downloads: the scene picker now has checkboxes plus 'Check all'/'Clear checks' buttons, and 'Download and build' processes every checked scene in one run, keeping each scene's files in its own subfolder; a failing scene is skipped and reported at the end while the rest still complete (double-click still downloads a single highlighted scene). ; 0.4.5 - bugfix: the scene footprint outline is now removed from the map correctly when the scene picker closes - QgsRubberBand is a QGraphicsItem (not a QObject) in QGIS 3, so the old cleanup called a non-existent deleteLater() and logged an AttributeError; the band is now detached from the canvas scene instead. ; 0.4.4 - packaging fix: the plugin ZIP now contains a top-level 'sentinel_mpc' directory, as required by the QGIS 'Install from ZIP' dialog - the 0.4.1-0.4.3 archives laid the files out flat and were rejected by QGIS as an invalid plugin; no functional changes, the code is identical to 0.4.3. ; 0.4.3 - scene footprint outline: the footprint of the scene selected in the picker is highlighted on the map as a transient outline, and the scene picker is now non-modal so you can pan/zoom and see how the scene fits the search area; 'All bands' option: both the Sentinel-2 and Landsat tabs now offer an explicit 'All bands' item (and Sentinel-2 gained individual band downloads B01-B12 except B10, which is not delivered in L2A). ; 0.4.2 - code-review follow-ups: SAS token refresh no longer holds a global lock during the network request (single-flight per collection, other threads keep working); defensive fixes - a non-numeric cloud cover no longer breaks the scene table, thumbnail cache pruning tolerates files deleted mid-listing, a POST-merge pagination link after a GET page no longer raises, default output folder renamed to MPC_Downloader (existing installations keep their setting); Warp resampling no longer oversubscribes CPU when several bands are resampled in parallel; dead code removed, menu renamed to 'Sentinel / Landsat'. ; 0.4.1 - QGIS 4 (PyQt6) compatibility: QAction is now imported from QtGui with a Qt5/QtWidgets fallback (the plugin previously failed to load under QGIS 4); cancelling an index build closes the GDAL datasets before deleting the partial file (Windows used to leave a stray GeoTIFF); 'From canvas' reports a friendly error for degenerate or dateline-crossing extents. ; 0.4.0 - Landsat support: new Landsat tab with missions 4-9 (Sentinel-2 unchanged on its own tab), 4 standard RGB syntheses (True Color, False Color, SWIR, Agriculture) and NDVI for Landsat 5-9, per-band downloads and RGB composites for Landsat 4, individual band downloads for all missions, WRS-2 path/row shown in the scene table, correct Landsat surface reflectance scaling (0.0000275/-0.2) for NDVI. Note: Landsat 1-3 (MSS) are not hosted on Microsoft Planetary Computer. ; 0.3.0 - code review pass: shared HTTP sessions with connection reuse, byte-range resumable downloads (.part kept on cancel/network drop), STAC pagination beyond the first page of results, parallel band resampling, thread-safe SAS token cache, safe dialog close during long GDAL jobs (no more QThread crash), GDAL error details in messages, duplicate-scene-id safe table, thumbnail cache pruning. ; 0.2.0 - fixed plugin loading (__init__.py), NDVI/NDMI correctness (uint16 overflow, BOA offset), pseudocolor renderer, background threads instead of a frozen UI, resumable downloads, Qt6/QGIS 4 compatibility.

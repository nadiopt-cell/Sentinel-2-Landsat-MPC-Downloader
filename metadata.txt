about=Searches Sentinel-2 L2A, Landsat Collection 2 Level-2 and ASTER L1T scenes through the Microsoft Planetary Computer STAC API (no VPN needed). Sentinel-2, Landsat and ASTER are on separate tabs; Landsat missions 4-9 are selected inside the Landsat tab (Landsat 1-3 / MSS are not hosted by Planetary Computer). Downloads only the bands required by the selected products, resamples Sentinel-2 20/60 m bands to 10 m and builds 8 RGB composites plus NDVI/NDMI for Sentinel-2 and 4 standard composites, NDVI and per-band downloads for Landsat, added to the project as GeoTIFFs. For ASTER (archive on Planetary Computer: 2000-03-04 to 2006-12-31) each granule holds up to three multi-band swath files (VNIR 15 m, SWIR 30 m, TIR 90 m) which the plugin downloads whole and splits into single bands; products: False Color (NIR/Red/Green), Geology (SWIR 4/6/8), a relative NDVI and all 14 bands as individual GeoTIFFs. Personal-use plugin, not published to the QGIS repository.

changelog=0.5.1 - bugfix: the scene preview now follows the checkbox - checking a scene in the picker moves the highlighted row and the map outline to that scene (a checked scene used to leave the outline on the previously selected row, so the preview seemed to stop working); a double-click on the checkbox cell no longer accepts the dialog (it used to pick that single scene and silently drop every other check); 'Check all'/'Clear checks' cause a single outline update instead of one per row; a failed preview batch is reported in the picker instead of leaving a silent frozen progress bar. ; 0.5.0 - ASTER L1T support: new ASTER tab (the Planetary Computer copy of the archive covers 2000-03-04 to 2006-12-31; ASTER images on demand, so scenes are irregular). Each granule holds up to three multi-band GeoTIFF swath files - VNIR (B01/B02/B3N, 15 m), SWIR (B04-B09, 30 m), TIR (B10-B14, 90 m) - which are downloaded whole and split into single bands; standard products: False Color (NIR/Red/Green), Geology (SWIR 4/6/8 - clays, carbonates, iron oxides) and a relative NDVI, plus all 14 bands as individual GeoTIFFs. 'Use ASTER archive dates (2000-2006)' button sets the shared date fields; searching a window fully outside the archive explains the limit instead of returning an empty result; the empty-search probe now knows the ASTER collection too. Tab note: some granules (night, fully overcast) carry only the thermal TIR swath, TIR bands are raw radiance counts (no temperature calibration) and NDVI is relative (ASTER L1T is not atmospherically corrected). Plugin renamed to 'Sentinel-2 & Landsat & ASTER MPC Downloader'. ; 0.4.9 - empty search diagnostics: when a search returns no scenes (Landsat revisits one place only every 16 days, so short date windows are often empty), the plugin re-checks the catalog with the window widened by +/-16 days and without cloud/mission filters, and explains what to do: it lists example scene dates nearby, or reports a network/access problem when even the filter-free probe finds nothing; the Landsat tab note mentions the 16-day revisit. ; 0.4.8 - the main window now fits small screens: the search form (area of interest, dates, data tabs, output options) lives in a scrollable area, while the progress bar, status line and buttons stay pinned at the bottom and always remain visible; the dialog opens at the form's natural size capped to the available screen, so on short screens a scrollbar appears instead of a window that does not fit. ; 0.4.7 - bugfix: downloading several large scenes no longer freezes the plugin window - the downloader used to report progress on every downloaded megabyte, flooding the Qt event queue with cross-thread signals (the window stopped responding and kept changing its shape);

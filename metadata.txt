about=Searches Sentinel-2 L2A and Landsat Collection 2 Level-2 scenes through the Microsoft Planetary Computer STAC API (no VPN needed). Sentinel-2 and Landsat are on separate tabs; Landsat missions 4-9 are selected inside the Landsat tab (Landsat 1-3 / MSS are not hosted by Planetary Computer). Downloads only the bands required by the selected products, resamples Sentinel-2 20/60 m bands to 10 m and builds 8 RGB composites plus NDVI/NDMI for Sentinel-2 and 4 standard composites, NDVI and per-band downloads for Landsat, added to the project as GeoTIFFs. Personal-use plugin, not published to the QGIS repository.

'All bands' option: both the Sentinel-2 and Landsat tabs now offer an explicit 'All bands' item (and Sentinel-2 gained individual band downloads B01-B12 except B10, which is not delivered in L2A). ; 0.4.2 - code-review follow-ups: SAS token refresh no longer holds a global lock during the network request (single-flight per collection, other threads keep working); Warp resampling no longer oversubscribes CPU when several bands are resampled in parallel; dead code removed, menu renamed to 'Sentinel / Landsat'. ; 0.4.1 - QGIS 4 (PyQt6) compatibility: QAction is now imported from QtGui with a Qt5/QtWidgets fallback (the plugin previously failed to load under QGIS 4); cancelling an index build closes the GDAL datasets before deleting the partial file (Windows used to leave a stray GeoTIFF); 'From canvas' reports a friendly error for degenerate or dateline-crossing extents. ;
